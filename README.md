# 学习项目合集（study-projects）

三个自制的学习工具网页。全部为纯静态页面，下载后双击各文件夹内的 `index.html` 即可在浏览器中打开，无需安装任何环境。

## 项目一览

### 1. 物理错题本 —— 高中物理刷题 APP

高中物理刷题工具：习题练习、错题本、题目管理、OCR 导入、难度评级、个性化推荐。

- 打开方式：`物理错题本/index.html`（文件夹内附 `使用说明.txt`）

### 2. 线代期中复习 —— 刷题网页 + 词典网页

- **刷题网页**：90 道线性代数交互刷题，支持选题、做题、判分（对 / 半对 / 错）、错题本、收藏、统计与随机组卷，公式由本地 KaTeX 渲染。
- **词典网页**：97 个线性代数英文术语的 EN-CN 可搜索词典。

- 打开方式：`线代期中复习/刷题网页/index.html`、`线代期中复习/词典网页/index.html`

### 3. 元素周期表 —— 学习工具网页

118 个元素的周期表学习工具：周期表 / 测试 / 错题本 / 账号管理四个视图，三种测试模式（go / plus / pro），支持发音（在线 TTS）。

- 打开方式：`元素周期表/index.html`

## 说明

- 学习数据保存在浏览器 localStorage，多账号互不干扰。
- 刷题网页与词典网页的公式渲染依赖 `线代期中复习/vendor/katex/`，请保持目录结构完整。
